# Сюжетні ролики Age of the Ring 10

47 сюжетних роликів гри в сюжетному порядку з субтитрами українською, англійською та іспанською.
Згенеровано скриптом `008_AoR/AoR_10/tools/export_cinematics.py` (перезапуск оновлює все).

| Номери | Розділ |
|---|---|
| 000 | Вступний ролик гри (`Overall_Game_Intro`, у грі це `CS01`) |
| 001–015 | Кампанія «Братство Персня» |
| 016–026 | Кампанія «Дві вежі» |
| 027–046 | Кампанія «Повернення Короля» |

7 роликів без мовлення (без субтитрів): `AOTRCampaign_08`, `AOTRCampaign_09`, `AOTRCampaignROTK_03b`, `_07a`, `_12a`, `_12b`, `_13b`.

## Вміст

| Шлях | Що це |
|---|---|
| `video/NNN_<Video>.mp4` | ролик: картинка з `.vp6` гри + озвучка (DialogEvent mp3), h264 / aac, 1024×640; ролики понад 25 МБ перекодовано до ≈ 19.5 МБ (двопрохідне кодування) |
| `audio/NNN_<Video>.mp3` | лише озвучка ролика — оригінальний mp3 гри (`aotr/data/audio/speech`, для вступу це `CS01.mp3`) |
| `subtitles/srt/uk/` | українські субтитри — вичитані, саме вони в українізаторі з версії 0.19 (40 роликів) |
| `subtitles/srt/en/` | англійські — таймінги іспанського сабмоду + розшифровка Whisper, звірено (40) |
| `subtitles/srt/es/` | іспанські — з сабмоду traduccion-es 1.2.2 (38) |
| `subtitles/cinematics_subtitles.json` | усе в одному файлі: кампанія, номер, fps, тривалість, репліки трьома мовами (секунди й кадри) |
| `subtitles/game/<мова>/data/english/movies/<Video>.ini` | ігровий формат: один INI на ролик (рушій BFME2/RotWK) |
| `subtitles/game/<мова>/subtitles_<мова>.str` | рядки `SUBTITLE:<LL><Video>_NN` для цих INI (формат `lotr.str`) |
| `subtitles/game/video.ini` | `video.ini` AoR 10.0.2 з `HasSubtitles = Yes` для роликів із субтитрами |

## Ігровий формат

- Кадри (`StartFrame` / `EndFrame`) рахуються за fps самого ролика: 24, 25, 23.976 або 30 (`AoR_10/movie_subtitles/fps.json`).
- Шрифт `Albertus MT`, розмір 24, один рядок (`Line:15`).
- Кожна мітка `SUBTITLE:` з INI має існувати в рядках гри (`lotr.csf`), інакше гра падає при запуску.
- Префікси міток: `UA` (українська, як в українізаторі), `EN`, `ES`.
- `video.ini` замінює файл AoR цілком: після оновлень AoR його треба зібрати заново.
- Українські INI й тексти тут байт у байт такі самі, як в українізаторі.

## Розмір

Жоден файл не більший за 25 МБ (обмеження завантаження на GitHub): 12 найбільших роликів
(вступ, 5 з «Двох веж», 6 з «Повернення Короля») перекодовано з 26–71 МБ до ≈ 19.5 МБ.
Інші ролики — без змін, у якості збірки для перегляду.
