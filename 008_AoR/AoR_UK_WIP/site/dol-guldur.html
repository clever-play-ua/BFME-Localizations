How to translate
  1. Pick the fortress, a hero or a building on the left. Its buttons and tooltips appear as cards: the English tooltip on the left, the Ukrainian one on the right, drawn the way the game draws them.
  2. Click into the Ukrainian tooltip and type — you see at once how it will look in the game. Everything you type is kept in this browser automatically.
  3. Tick Reviewed when a line is final, even if you did not change it.
  4. Enter your nickname at the top (required), press Export JSON and send the downloaded file to the team. The file holds all your changes from every page of the site (factions and heroes) — one export is enough. A line shared by several pages is the same line everywhere. Import JSON loads such a file back (for example on another computer).

Rules

  • The hotkey (&W) is added automatically — just type the name.
  • Keep %s, %d, %% exactly as in English.
  • Enter makes a new line in the game too — use it to keep long lines readable.
  • Use the straight apostrophe ', not ʼ — the game font has no ʼ.
  • Some texts are used by several units. Editing one copy changes all of them.

Browser storage is per device and per browser. Clearing site data deletes work that was not exported.
