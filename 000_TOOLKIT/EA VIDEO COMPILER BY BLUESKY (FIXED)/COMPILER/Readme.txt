EA Movie encoder.
This encondes a movie into your game.

Instruction:
1. Install Codecs, Net Runtime and Visual C++ 2005 in "INSTALL FIRST" Folder
2. Get MP4 H264 and drag into MP4 folder.
3. Choose the option, select the right frame rate and compile it.
4. For vp6 it ask for bitrate.
5. It get to Release folder copy to your game.
